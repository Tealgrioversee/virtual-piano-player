## 💡 What Is Virtual Piano?

**Virtual Piano Player** is a software application that turns your computer keyboard, mouse, or MIDI controller into a fully playable piano. It's designed for musicians, students, hobbyists, and anyone who wants to learn or play piano without purchasing a physical instrument.

Whether you're practicing scales at midnight, composing your first song, or teaching a class — the virtual piano adapts to your needs with a professional sound engine and intuitive interface.

## 🛠️ Installation Workflow

### Stage 1 — Web Version (Instant)

No installation — just open in browser:

1. Visit the provided URL
2. Grant audio permissions
3. Click any key to play

### Stage 2 — Desktop Installation

**Windows:**

```powershell
.\VirtualPiano-Setup.exe
```

**macOS:**

```bash
hdiutil attach VirtualPiano.dmg
cp -R "Virtual Piano.app" /Applications/
```

**Linux:**

```bash
chmod +x VirtualPiano.AppImage
./VirtualPiano.AppImage
```

### Stage 3 — Audio Setup

| OS | Recommended Driver |
|----|-------------------|
| Windows | ASIO4ALL |
| macOS | CoreAudio (default) |
| Linux | PipeWire / JACK |

Lower latency = better response time.

### Stage 4 — First Launch Wizard

The wizard configures:

1. 🎨 Interface theme
2. 🔊 Audio output device
3. 🎹 MIDI input device (if any)
4. ⌨️ Keyboard mapping
5. 📁 Save location

### MIDI Setup

1. Connect controller via USB
2. Open **Settings → MIDI Input**
3. Select your device
4. Enable **MIDI Thru** if daisy-chaining
5. Test by pressing keys

### MIDI File Import

Load `.mid` files to play them back:

```bash
virtual-piano --import song.mid
```

## 🛠️ Troubleshooting

| Problem | Cause | Solution |
|---------|-------|----------|
| ❌ No sound | Audio blocked | Allow audio |
| ❌ Latency | Buffer too high | Reduce to 128 |
| ❌ Keys unresponsive | Focus lost | Click window |
| ❌ MIDI not detected | Driver | Install driver |
| ❌ Recording distorted | Input too loud | Lower gain |
| ❌ Crashes | Memory | Close other apps |
| ❌ Notes stuck | Note-off missed | Restart app |
| ❌ Wrong instrument | Selection | Change in menu |
| ❌ Sheet won't load | Format | Use MusicXML |
| ❌ Export fails | Disk full | Free space |
